# Supplementary materials of "Cardiac 3D Motion Reconstruction Using Dual-Camera Defocused Speckle Imaging with Multi-Scale Amplification"

This repository contains the official supplementary materials for the paper "Cardiac 3D Motion Reconstruction Using Dual-Camera Defocused Speckle Imaging with Multi-Scale Amplification".

It contains the following content:

1. Summary of related research on cardiac activity monitoring;
2. Algorithm of signal segmentation;
3. Experimental Protocols and System Parameters;
4. Feasibility Testing Experiment;
5. Waveform Morphology Analysis in a Controlled Laboratory Scenario;
6. Waveform Visualization in Laboratory and ICU Scenarios;
7. Localization Accuracy of Six Biomarkers.
